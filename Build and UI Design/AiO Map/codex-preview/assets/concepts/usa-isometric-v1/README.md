# USA isometric map concepts

Created 2026-09-21 with the built-in image_gen tool.

Project purpose: visualize customer interview filming across all 50 US states, showing who was interviewed and where, and adding new interviews.

These three raster images establish visual style. California and Texas highlights represent selection examples, not real filmed customer locations. Use the project's geographic data for interactive state boundaries and location placement; generated illustrations are not authoritative geographic data.

Style: matte white extruded states, pale cool gray ground, soft shadows, turquoise selection, minimal floating state label. Alaska and Hawaii appear as insets.

Replace European countries completely with a geographically recognizable United States map including all 50 states: 48 contiguous states in correct relative locations and separate Alaska and Hawaii insets below left, with all Hawaii islands represented. Precise recognizable state silhouettes and boundaries, no invented divisions, preserve Great Lakes and coastlines. No app chrome, no people, no buildings, no decorative objects, no pins, no text, no watermark, no reference screenshot borders or Save button. Create a fresh high quality image, not a screenshot.
