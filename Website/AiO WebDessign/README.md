# AiO Studio — Marketing Website

Landing page marketing tương tác cho AiO Studio, giới thiệu bốn công cụ:

- **Asset Manager** — thư viện media không giới hạn, nhận từ mọi nguồn và preview tức thì.
- **Power Bins** — Brand Kit dùng chung cho nhiều project.
- **Auto Cut** — tự chọn cảnh, loại khoảng lặng và dựng theo nhịp.
- **Auto Transcripts** — transcript, nhận diện người nói và xuất phụ đề.

Trang bao gồm hero sản phẩm, lợi ích, bốn feature card, demo tương tác, quy trình ba bước và CTA.

## Chạy tại máy

Yêu cầu Node.js 22.13 trở lên.

```powershell
npm install
npm run dev
```

Địa chỉ mặc định: `http://localhost:3000`

## Kiểm tra bản dựng

```powershell
npm test
```
